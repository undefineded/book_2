# 鸟类小百科纸签 · 无字 SVG 重绘

参照鸟类绘本 P15「老街上的歌手」的小百科纸签，移除标题与正文文字，用 SVG 重绘纸张和装饰。保留参考图的画布比例、自然轮廓、暖奶油色纸底、橙色装饰虚线、金黄标题条及左上、右下绿叶。

- [可编辑 SVG](鸟类小百科-无字背景.svg)：画布 1254×1254，透明背景。可用 Inkscape、Illustrator 等矢量工具打开。
- [透明 PNG](鸟类小百科-无字背景-1254px.png)：由上述 SVG 直接渲染，1254×1254，RGBA。

SVG 的所有可见元素均由路径、渐变、裁切路径和程序纹理滤镜构成，没有绘制文字的 `<text>` 对象、嵌入位图或外链资源。纸张、纸纹、虚线、标题条与树叶均有独立命名分组。SVG 的纸纹和水彩色块为近似表现；它是参照原图的矢量重绘。

主要分组：`paper`（纸底）、`paper-texture`（纹理）、`inset-dashes`（虚线）、`blank-title-strip`（空白标题条）、`leaf-decorations`（叶片）。隐藏 `paper-texture` 可去掉纸纹；叶片的渐变、色块与叶脉可分别编辑。

验证：SVG XML 可解析；没有文字对象、位图或外链；PNG 四角 Alpha 为 0，纸张中心为不透明。PNG 使用 Inkscape 渲染，保留 SVG 滤镜效果；其他软件对纹理滤镜的显示可能存在差异。此样例独立保存，正式绘本素材保持原文件。
