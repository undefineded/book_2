# 绘本背景生成器 · 制作文档

版本：V0.1，供审阅。当前交付需求与制作方案，尚未开始编码。

## 1. 工具目标与本期范围

为绘本制作可调整形状、可重复编辑的无字背景素材，提供两个独立入口：**标题背景**和**小百科背景**。

本期只生成背景、虚线、装饰和可选阴影。标题、正文、百科内容由后续字库排版流程添加；导出的背景不含文字。现有绘本原图继续作为排版素材使用，不在本工具中改画。

建议首先制作**中文桌面浏览器版**，在本地完成编辑与导出，不依赖图片生成接口。背景由形状、纹理、透明度和装饰参数构成，修改后可直接重新绘制。

| 模块 | 用户操作 | 工具输出 |
|---|---|---|
| 标题背景 | 添加背景 → 自由推拉 → 调节边缘透明 → 导出 | 自然轮廓、暖奶油阅读底、渐隐透明边缘 |
| 小百科背景 | 添加背景 → 选形状 → 拉宽或拉高 → 确认 | 奶油纸签、随轮廓排列的裁切虚线、树叶装饰 |

本文先将“裁切线”按绘本现有纸签样式理解为**沿轮廓内侧排列的装饰虚线**；其内缩距离可调。实际印刷刀线属于另一种交付规格，不与装饰虚线混用。

## 2. 界面与通用操作

### 2.1 页面布局

```text
顶部：新建 / 打开项目 / 保存 / 撤销 / 重做 / 导出
┌────────────┬─────────────────────────┬────────────────┐
│ 标题背景    │                         │ 当前对象属性    │
│ 小百科背景  │      中央编辑画布        │ 形状 / 尺寸     │
│ 对象列表    │      透明棋盘格预览      │ 颜色 / 纹理     │
│            │                         │ 羽化 / 装饰     │
└────────────┴─────────────────────────┴────────────────┘
底部：画布像素尺寸 / 缩放比例 / 适应画布 / 100%查看
```

- 画布默认1254×1254px，可新建自定义尺寸。形状宽高与画布宽高分开设置。
- 每次点击“添加”都会新增一个背景对象，不覆盖已有对象。一次编辑一个对象，可选择、移动、复制、删除、锁定及调整前后顺序。
- 两种背景可以放在同一项目中。对象列表使用“标题背景1”“小百科背景1”等名称，可重命名。
- 支持滚轮缩放、空格拖动画布、撤销和重做。一次连续拖拽记为一个撤销步骤。
- 棋盘格、白底、深色底用于检查透明边缘；可导入绘本原图作为参考底图。参考底图默认锁定，且不进入背景素材导出。
- 形状外接框与内容安全区为编辑辅助线，不进入导出文件。

### 2.2 尺寸与编辑状态

第一版建议支持单边256—4096px的画布。超出支持范围时在输入框旁提示，不直接清空项目。

每个对象保留可编辑参数。“完成形状”“确认形状”用于切换编辑阶段，不把对象永久压成一张不可修改的图片。重新进入形状编辑后，仍可调整并撤销。

## 3. 标题背景工具

### 3.1 添加一个背景

点击“添加标题背景”，在画布中央新增一块柔和的暖奶油背景：轮廓略有自然起伏，中心适合承托标题与短正文，四周留出透明区域。

初始背景提供三种起点：圆角长方形、柔软椭圆、自然云团。用户选择起点后，可继续自由推拉，不受预设形状限制。

可设置底色、中心暖色渐变强度、整体不透明度、纸纹强度。纸纹默认轻微，不影响之后的文字阅读。

### 3.2 类似液化的推拉

工具栏分为“选择移动”和“推拉形状”，防止拖动对象与推拉轮廓混淆。

选中“推拉形状”后：

1. 光标显示圆形画笔，画笔大小可调。
2. 按住鼠标拖拽，画笔范围内的背景局部随拖拽方向移动，可向外拉出、向内推回，也可沿边缘调整起伏。
3. 松开鼠标后轮廓保持平滑，未经过的远处区域保持稳定。
4. 可切换“局部恢复”画笔，逐步恢复经过位置的形状；也可一键重置当前背景轮廓。

第一版实现“向前推移”和“局部恢复”，不加入旋涡、膨胀、人像液化等其他工具。

| 参数 | 初始建议 | 操作效果 |
|---|---|---|
| 画笔直径 | 背景短边的约20% | 控制推拉影响范围 |
| 推拉力度 | 30% | 控制一次拖动的形变幅度 |
| 边缘柔顺度 | 中等 | 平滑局部轮廓，减少尖刺 |

参数是初始建议，开发时结合实际手感调整。轮廓不得因快速拖动出现交叉、翻折、破洞或断裂；临近此类情况时限制本次形变幅度。纸纹在修改后的背景中重新绘制，避免被拉成长条。

### 3.3 完成后进行边缘透明化

点击“完成形状”，进入“边缘透明”面板。默认对整个外轮廓做连续羽化，可调节：

- **羽化宽度**：从外边缘向内部逐渐过渡的距离。
- **过渡柔和度**：控制透明到实色的变化节奏。
- **整体不透明度**：调节背景承托文字的强度。
- **柔和阴影**：默认关闭；可调整颜色、强度、模糊范围与偏移。

羽化作用于透明度，外边缘降到完全透明，中心保留稳定底色。不能用白色或灰色填充假装透明，也不能产生一圈白边。

背景过窄、羽化范围过大时，自动限制羽化宽度并显示调整结果，避免整块背景都变淡、失去阅读承托效果。用户可返回推拉阶段修改形状；羽化会自动沿新轮廓更新。

### 3.4 标题背景完成流程

```text
添加标题背景 → 选择初始形状 → 局部推拉 → 完成形状
→ 调节边缘透明与可选阴影 → 检查浅底/深底效果 → 导出
```

## 4. 小百科背景工具

### 4.1 添加与选择预设形状

点击“添加小百科背景”，打开形状面板。第一版至少提供以下六种预设，均保留足够的中央内容区域：

| 预设 | 外形 | 适合用途 |
|---|---|---|
| 圆角纸卡 | 四边平稳，圆角柔和 | 通用百科、较长段落 |
| 柔波纸签 | 四周轻微波浪起伏 | 接近现有绘本纸签 |
| 云朵纸签 | 较明显的圆润凸起 | 短贴士、童趣内容 |
| 自然纸片 | 轻微不对称边缘 | 手账与观察提示 |
| 椭圆纸签 | 连续椭圆轮廓 | 较短知识点 |
| 切角纸签 | 柔和切角、平稳主体 | 分类提示、互动说明 |

默认使用暖奶油纸色、轻纸纹与细纸边。形状预览不添加任何文字。

### 4.2 只允许拉宽或拉高

形状仅显示左、右、上、下四个拉伸手柄：

- 拖左/右手柄只改变宽度，另一侧固定，高度不变。
- 拖上/下手柄只改变高度，另一侧固定，宽度不变。
- 可直接输入宽度或高度，单独修改对应方向。
- 不提供四角斜拉、局部液化或自由轮廓编辑。移动对象使用选择移动模式。

拉伸后按新的宽高重新计算纸签轮廓，保持纸边、圆角与自然起伏的观感。纸纹保持合理颗粒尺寸。虚线线宽、树叶宽高比等装饰参数不跟随纸签作非等比缩放。

### 4.3 确认形状后自动添加虚线与树叶

点击“确认形状”，自动完成以下步骤：

1. 沿当前纸签轮廓向内生成一圈裁切虚线，线条不穿出纸外，转角处保持连续自然。
2. 默认在左上和右下放置两组手绘树叶，与纸边自然搭接。
3. 显示内容安全区，让后续排字能避开虚线与叶片。
4. 可开启空白金黄色标题条。标题条只提供底色，不自动写“鸟类小百科”等文字。

确认后可调整的项目：

| 类别 | 可调项目 |
|---|---|
| 裁切虚线 | 开关、颜色、线宽、虚线长度、间隔、距纸边的距离 |
| 树叶装饰 | 开关、样式、位置组合、大小、旋转、轻微位置调整 |
| 标题条 | 开关、宽高、颜色、位置 |
| 纸张 | 底色、纸纹强度、细边颜色、柔和阴影 |

树叶首版提供细长叶、小圆叶、成簇嫩叶三组样式。默认位置为左上＋右下，可切换右上＋左下、仅左上、仅右下。更换叶片样式与调整尺寸均不重新抽取随机位置。

叶片可轻微伸出纸签轮廓，导出范围必须包含完整叶片及阴影；纸边虚线保留在纸内。内容安全区应避开叶片覆盖区域和标题条，可在画布中显示但不导出。

### 4.4 确认后再次改变宽高

选择“调整形状”可继续拉宽或拉高。拖拽时提供轮廓预览，完成后按新形状重算虚线、标题条和树叶锚点：

- 虚线沿新的轮廓排列，保持线宽和节奏。
- 树叶保持自身比例，跟随相应角部移动，不被拉扁。
- 用户对叶片做过的局部位移、旋转，以角部锚点为基准保留。
- 纸签太小时限制装饰尺寸，避免两组叶片挤在一起、挤占全部内容区。

### 4.5 小百科背景完成流程

```text
添加小百科背景 → 选择预设 → 只拉宽/拉高 → 确认形状
→ 自动生成裁切虚线和树叶 → 按需微调装饰 → 导出
```

## 5. 保存与导出

### 5.1 默认交付格式

- **透明PNG**：RGBA，真实Alpha通道，画布底色和棋盘格不进入图片。
- **项目文件**：JSON，保存画布、对象、轮廓、推拉结果、颜色、羽化、虚线、装饰锚点和纹理种子，可重新打开编辑。
- **自定义预设**：保存当前背景参数，之后一键复用同类纸签或标题底。

可选两种导出范围：

1. **选中对象**：按对象及其完整效果范围自动裁切，外加透明余量；适合独立素材。
2. **整个画布**：保留对象在画布中的位置；适合对齐后续排版。

选中对象导出时，四边透明余量默认24px，可调整。计算范围包括羽化、树叶、纸边与阴影，不能只按纸张主体裁切。

### 5.2 输出尺寸

导出面板明确显示最终像素宽高。修改导出尺寸时，从形状与参数重新渲染对应像素，不拉伸已有低分辨率截图；纹理与线条也按目标尺寸绘制。

第一版导出PNG和可编辑项目文件。批量导出、SVG/PDF以及字体排字列为后续扩展，不作为本期完成条件。

## 6. 建议实现方案

本节为开发建议，不在用户操作界面展示。

- 使用TypeScript与浏览器Canvas实现编辑和最终PNG渲染；界面框架建议React。
- 形状保存为可编辑的轮廓数据，标题背景使用带平滑衰减的局部推移。检测轮廓交叉、限制最小厚度，保证液化效果可用。
- 羽化根据修改后的轮廓距离计算透明度，使背景外部透明、内部保留稳定底色；阴影单独绘制在背景后方。
- 小百科预设使用参数化路径，按新宽高重新绘制，虚线依据路径长度排列。树叶使用独立矢量素材，保持比例，以角部锚点定位。
- 图层顺序依次为阴影、纸张/阅读底、纸纹、纸边与虚线、标题条、树叶；辅助线只参与编辑预览。
- 纹理使用固定种子，项目重开、撤销、改变预览缩放或重复导出时保持一致。
- 鼠标交互采用低延迟预览，松开后完成精细绘制；最终导出以项目尺寸渲染，与屏幕缩放比例分开计算。
- 第一版以本地文件保存和打开项目，保存后可断网继续使用；不要求账号、云端存储或服务端图片生成。

## 7. 制作顺序与交付物

| 阶段 | 完成内容 | 可审阅交付 |
|---|---|---|
| 1. 基础编辑器 | 画布、对象管理、尺寸、撤销重做、项目保存 | 可添加和管理背景的浏览器工具 |
| 2. 标题背景 | 初始形状、局部推拉、恢复、羽化、透明导出 | 一张可自由塑形的标题阅读底 |
| 3. 小百科背景 | 六种预设、单轴拉伸、确认后自动装饰 | 六种完整纸签及各类拉伸结果 |
| 4. 样式与验收 | 奶油色、纸纹、树叶、阴影、边界与导出检查 | 完整工具、使用说明和示例项目 |

最终应交付可运行工具、简明使用说明、默认形状与树叶素材、自定义预设示例、可重新编辑的示例项目。所有示例背景保持无字。

## 8. 验收标准

| 检查项 | 通过标准 |
|---|---|
| 添加背景 | 连续添加两个对象，原对象保留，可分别选择编辑 |
| 标题推拉 | 能在局部拉出和推回轮廓，远处不跟着整体移动；无交叉、破洞与断边 |
| 边缘透明 | 浅底和深底下均平滑，无白框；效果范围外Alpha为0，中心保留承托底色 |
| 阶段切换 | 已羽化的标题底仍可重新塑形，透明边缘随新轮廓更新 |
| 小百科预设 | 至少六种轮廓，均可独立拉宽或拉高，无斜向拉伸与液化入口 |
| 单轴约束 | 修改宽度后高度数值不变，修改高度后宽度数值不变 |
| 自动装饰 | 确认形状后自动出现裁切虚线与树叶，空白标题条按开关显示 |
| 装饰重排 | 分别拉宽、拉高后，虚线沿新轮廓排列，叶片比例与线条粗细保持合理 |
| 内容空间 | 安全区避开虚线、叶片与标题条；极窄形状会限制到可用尺寸 |
| 透明导出 | PNG无棋盘格、辅助线、参考底图和文字，叶片及阴影完整无截断 |
| 尺寸一致 | 导出像素与面板显示一致，预览缩放不改变导出大小 |
| 保存恢复 | 关闭后打开项目，形状、纹理、装饰位置与编辑状态可恢复 |
| 撤销重做 | 可逐次恢复形变、羽化和尺寸调整，拖拽不会产生大量重复步骤 |

审阅重点为：液化式推拉的操作定义、六种小百科预设、虚线与树叶的默认布局，以及本期只制作无字背景的范围。
