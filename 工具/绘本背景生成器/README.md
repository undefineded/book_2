# 纸间 · 绘本背景工坊

在本地制作绘本用的无字标题底和小百科纸签，导出带真实透明通道的 PNG。第一版支持局部推拉、轮廓羽化、六种纸签、内缩虚线、树叶装饰及可编辑项目保存。无需账号或图片生成接口。

## 直接使用

1. 下载 [离线版：绘本背景工坊.html](release/绘本背景工坊.html)。在 GitHub 文件页选择 **Download raw file** 下载完整文件。
2. 用桌面版 Chrome 或 Edge 打开下载的 HTML，即可断网编辑。程序、样式和装饰均已包含在这一个文件中。
3. 首次打开会看到一块标题底和一张百科纸签。可直接修改，也可以点击顶部「新建画布」。

[打开示例项目](examples/标题与百科背景.paper.json)需先下载 JSON，再通过工具顶部的「打开项目」导入。示例没有文字，也不依赖外部图片。

## 标题背景

1. 点击左侧「标题背景」，选择形状起点。
2. 选择「推拉」或按 `B`，沿背景边缘拖动。右侧可调画笔大小和力度；「局部恢复」恢复画笔附近的形状，「重置当前轮廓」恢复整块轮廓。
3. 点击「完成形状，调节透明」，设置羽化宽度、过渡柔和度、颜色、纸纹和整体透明度，可按需添加阴影。
4. 切换白色或深色预览底，检查透明过渡。需要继续塑形时点击「重新调整形状」。

羽化沿当前轮廓向内作用于 Alpha，保留中心底色；极窄背景会自动限制羽化宽度。预览底色不进入导出。

## 小百科背景

1. 点击「小百科背景」，选择圆角纸卡、柔波纸签、云朵纸签、自然纸片、椭圆纸签或切角纸签。
2. 拖动左、右边中点只改变宽度；拖动上、下边中点只改变高度。也可在属性中输入宽高，按 Enter 或移出输入框生效。
3. 点击「确认形状，添加装饰」，自动添加内缩虚线、两组树叶与空白标题条。
4. 调整虚线内缩、长度、间隔、线宽和颜色；树叶可换三种样式、位置组合，并分别微调两组的位移及旋转。纸边细线、标题条和阴影也可调整。

再次改变纸签宽高时会重新计算内缩路径和装饰位置；叶组保持比例，虚线粗细保持设定值。内缩过大时自动减小到有效范围，面板显示实际距离。这里的「裁切虚线」是纸签内侧的装饰线，交付格式为透明 PNG。

## 保存、预览与导出

- **保存项目**：下载 `.paper.json`，包含对象、轮廓、颜色、装饰、纹理种子及参考图，之后可打开继续编辑。
- **自动保存**：保存在当前浏览器的 IndexedDB；自定义预设也保存在此。浏览器禁止本地存储时会显示提示，仍可手动保存项目。换浏览器或换文件位置时，请通过 JSON 转移项目。
- **保存为我的预设**：保存选中背景，下次从左侧一键添加副本。
- **参考底图**：在右侧导入 PNG、JPG 或 WebP，供叠放检查；只参与预览，不进入 PNG。
- **选中背景导出**：按实际透明范围裁切，包含完整叶片与阴影，默认额外保留 24px 透明余量。
- **整个画布导出**：保留全部背景的位置，画布范围外的内容按画布边界裁切。
- **输出尺寸**：修改导出宽度，高度按比例计算。程序根据形状重新渲染，导出结果与画布缩放比例无关。属性里的宽高是纸张主体大小，单对象 PNG 还会包含装饰和透明余量。

画布每边支持 256—4096px；每个项目最多 30 个背景。PNG 最终宽高均限制在 4096px 内。较大背景导出时需要等待绘制完成。程序只制作背景与装饰，文字需在后续排版流程添加。

## 操作快捷键

| 操作 | 快捷键 |
|---|---|
| 选择、移动 | `V` |
| 标题推拉 | `B`，在标题塑形阶段可用 |
| 平移画布 | 按住空格拖动，或鼠标中键拖动 |
| 缩放 | 鼠标滚轮、底部加减按钮 |
| 原尺寸查看 | 点击底部百分比 |
| 撤销、重做 | `Ctrl/⌘ Z`、`Ctrl/⌘ Shift Z`，也支持 `Ctrl/⌘ Y` |
| 保存项目 | `Ctrl/⌘ S` |
| 删除选中对象 | `Delete` 或 `Backspace`，输入文字时不触发 |

连续拖拽记为一次撤销，历史最多保留 50 步。左侧可选择或锁定图层；右侧可重命名、复制、删除和调整叠放顺序。锁定对象需先解锁才能修改。

## 开发与构建

需要 Node.js 22.12+ 或 24+。

```bash
npm ci
npm run dev
npm test
npm run build
npm run test:release
```

`npm run build` 先执行 TypeScript 检查，再构建常规静态站点到 `dist/`，最后生成 `release/绘本背景工坊.html` 和第三方许可。`dist/` 与 `node_modules/` 不提交；离线交付文件和源码一起提交。

技术栈：React 19、TypeScript、Vite、Zustand、Canvas 2D / Path2D、Clipper 多边形内缩、IndexedDB。树叶为程序绘制的独立矢量轮廓，纸纹使用固定种子，项目重开后保持一致。第三方依赖许可见 [第三方许可](release/第三方许可.txt)。

## 验证情况与边界

- 44 项自动检查：轮廓与内缩、局部形变、单轴尺寸、项目校验、撤销重做、界面操作，以及原生 Canvas 的 Alpha、羽化、装饰完整性和 PNG 像素尺寸检查。
- 离线包另有 DOM + 原生 Canvas 启动检查，执行打包后的代码，验证启动、添加标题、完成塑形、保存 JSON 和实际 PNG 下载流程，检查无外部资源引用。
- 构建与以上检查已通过。当前环境的浏览器预览转发未能就绪（`sites-preview` relay 超时），因此尚未完成真实浏览器的鼠标手感、屏幕布局和兼容性验收；DOM 与原生 Canvas 检查不代替真实浏览器验收。

第一版不含字体排字、批量导出或 SVG/PDF 导出。完整制作要求见 [制作文档](制作文档.md)。
