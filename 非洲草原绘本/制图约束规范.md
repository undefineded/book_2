# 《非洲草原大冒险》制图约束规范

与[制图剧本](制图剧本.md)、[通用约束规范](../制图规范/通用制图约束规范.md)共同使用。目前只有剧本，尚无正式图像或阅读PDF。

- 场景锁定东非坦桑尼亚塞伦盖蒂的稀树草原、灌丛、固定观景路线和季节性水塘，不能把所有物种集中在同一小块地面。
- 时段为旱季末向雨季过渡的一天；P39为回程后的次日清晨。P35才下雨，不能下一页立即变成满塘水、茂盛青草或大迁徙。
- P4足迹位于能留下印痕的湿泥或渐干泥地，不在坚硬石路上画清楚蹄印。不能由单个脚印直接断定物种、时间、方向与目的。
- 不出现老虎、亚洲象、袋鼠、南美金刚鹦鹉，不把沙漠或热带密林物种随意搬到开放草原。
- 小满保持5岁身份、脸型和短发，衣着、鞋帽按剧本所定天气、路线与活动；羽羽保持戴胜鸟物种特征及书挂件。
- 观察活动遵循剧本规定的车辆、向导和安全距离，不摸、不喂、不追逐、不捡走动物植物，不为了构图让儿童贴近危险动物。
- 足迹、水位、风向、动物动作与因果关系以逐页剧本为准；动物不主动充当讲解向导，不为讲知识排成队。
- 后续生成采用1254px方形无字场景、独立手写标题正文与专用透明纸签；没有实际制图前不宣称完成图页。
