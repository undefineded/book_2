# 《贝壳图书馆》代表页试画

本目录保存用于确认视觉方向的1254×1254无字试画，均保留图像生成工具直接输出的PNG。

整本图页见[40 页无字图索引](../正式素材/README.md)。跨页制作约束已记录在[绘本制作技能](../../skills/childrens-picturebook-illustration/SKILL.md#贝壳图书馆制作约束)。

- [P1｜贝壳图书馆](<../正式素材/P1｜封面：贝壳图书馆/无字图-1254px.png>)是当前封面。小满从沙丘栈道望向夕阳下的宽沙滩和大海，沙上散落三块大礁石，近水礁石旁有一汪浅潮池，远处有海鸥和小船。上方天空留给书名、副标题和导语。
- [P2｜书页上有水痕](<../正式素材/P2｜扉页：书页上有水痕/无字图-1254px.png>)是当前扉页。小满盘腿坐在凳面上，大腿和小腿保持儿童比例，膝盖与双脚向身体中间收。
- `P15｜珊瑚是动物还是房子-无字试画.png`以枝状珊瑚为主体。镜头保持适合印刷的场景尺度：小满与珊瑚处于同一中景层，她的目光和指向枝端的手共同构成观察关系；前景为礁石与海草，背景向后过渡为海底与沙地。羽羽停在水面上方的栏杆上。
- `P33｜夜里，它们出来了-无字试画.png`：夜间潮池、栈道安全观察与头灯光圈测试。

人物尺度应保证表情与动作清楚，同时让四周环境自然延伸。

## 本轮踩坑与后续制图约束

1. **先定叙事空间，再拉镜头。** 需要“观察”的页面，人物、观察对象与视线终点必须处在能互相成立的同一空间层级。不能只因要补环境而把人物推到远处、把观察对象留在特大前景；这样会断开“正在观察什么”的关系。
2. **人物比例以可读动作优先。** 场景要完整延伸到画幅四边，为装订和印刷留出余量；但人物不能缩成远景点。应先保证表情、手势和互动对象可读，再用前中后景补足环境。
3. **水下页必须明确水面与景深。** 水面、水下人物、观察对象、礁石或沙地应有稳定的前中后景层次；水面上的羽羽与栏杆须保持干燥，不能产生悬浮或水陆混层。
4. **手、四肢和目光需要逐页质检。** 小满必须有两条完整手臂、两条腿及合理的关节关系；可见手掌应有四指加拇指。目光、脸部朝向和手势应共同指向当前叙事对象。
5. **固定角色与道具跨页保持一致。** 羽羽须保留戴胜的冠羽、细长下弯喙和小红书挂件；如出现录音机等固定道具，外形、相对大小和使用方式需沿用已确认版本。
