# 《贝壳图书馆：从潮池到远海的蓝色大百科》

40 页章节分镜稿｜1:1 方形｜4—8 岁亲子共读｜修订版

本稿参照《羽毛图书馆：会飞的鸟类大百科》与《热带雨林大冒险》的版式体例编写，沿用小满与羽羽，建立独立的海洋故事。全书以一片海岸的一天一夜为舞台——"向上飞／横向走入／向下入水"三本里，这是"向下入水"的一本。配套图页尚未制作，本文件为制图依据。

## 全书设定与使用说明

### 故事主线

旧绿皮自然百科的扉页上，多了一道慢慢晕开的水痕。小满夹进第三枚书签——一枚小小的贝壳——书页亮起蓝色的光，把她和羽羽送到一片退潮后的海岸。

一天里，潮水退下去又涨回来。小满从不敢把脚伸进潮池，到敢跪在浮台上把脸埋进水面；从只能看见水面上的波纹，到能看见水下的花园。她一路只做三件事：看、画、问。天黑以后，潮水重新盖住沙滩，把白天的痕迹全部抹平。她带着一本画满的笔记回到图书馆，把海留在了原处。

推进力来自**退潮与涨潮**本身：水位的每一次变化，都会打开一处新的地方，也关上一处旧的地方。不靠追逐、救援或危机制造高潮。

### 地域与时间

- 取景范围为**一处亚热带海岸及其近岸浅海**：沙滩潮池、近岸礁盘、开阔海面、夜间的同一片海滩。呈现同一片海在不同水深与不同时段的样子，不宣称所有物种生活在同一处礁石或同一片沙滩。
- 全书时间线为**一个大潮日**，从清晨低潮到夜间涨潮，共约十四小时。魔法书页负责图书馆与海岸之间的往返，野外场景保持真实环境连续。
- P1 是概括主题的海报式封面，不是正文中的先行事件。故事从 P2 的清晨图书馆开始：书页出现水痕，小满夹入贝壳书签，书页发光，P3 接续进入海岸。魔法只负责空间转场，不替代人物脚下的支撑。
- 本书使用亚热带近岸与开阔海可见的动物与藻类，不混入极地、深海热泉、珊瑚三角区特有等超出设定海域的物种。羽羽是随书而来的戴胜鸟书精灵，不是海鸟，**它不会潜水**，这一点在第二章必须画出来。
- 海上段落使用一条**吃水浅的小观察船**，按潮水时间出海与回港，不在退潮后的浅滩久留。
- 天气以晴天与薄云为主，第二章午后可有一次短暂的风起浪高，用来交代"潮水盖住来时的路"，不安排风暴、落水或漂流情节。

### 人物与道具连续性

- **小满：** 5 岁，短黑发、圆润儿童脸型，保持同一年龄、脸型与发型。布包内有笔记本、彩铅、**防水画板**（本作新增的核心道具）和饮水瓶。人物比例、手腕连接、五指结构与自然遮挡须合理。
- **羽羽：** 金棕色戴胜鸟书精灵，细长微下弯黑喙、黑尖肉桂色扇形羽冠、黑白横斑翅膀、书签状尾羽；颈间细绳上保留砖红金边羽叶纹小书挂件。不可画成海鸥、鹦鹉或热带海鸟。它在水边的固定位置是**栏杆、礁石、缆绳等高于水面的支承物**。
- **自然百科：** 旧绿皮、米白厚书页。本作使用**贝壳形书签**——这是系列的第三枚书签，前两作分别是羽毛书签与叶形书签，三枚书签要在同一位置出现，形成可辨认的系列标记。P2 开启旅程，P12、P22、P31 用于核对观察，P36 带人物返回图书馆。
- **防水画板：** 一块米白色、四角带圆环的小画板，配一支防水笔，用绳子挂在布包外侧。它只能在水边和水面上使用，**不出现在水下**。P22、P31、P36 是它的三个主要戏份。
- **记录方式：** 观察后画图、写词、画问号。**贝壳、珊瑚、海藻、小动物一律只观察或画下，不带走。** 唯一被带走的是海上捞起的塑料垃圾——这一点要在 P29、P30、P36 三页前后咬合。
- **观察距离：** 不摸海葵、不抓蟹、不举海星、不追海龟；礁盘与潮池一律使用有完整护栏的木栈道、浮台或观察台阶；小满不独自下水、不在无护栏礁石上行走。第二章的"把脸埋进水面"必须发生在**有台阶与护栏的浮台上，水深不及膝**，且**不使用呼吸管**，只做短时间的屏气看水。

### 版式与文字规则

- 全部页面、封面和章扉均为 1:1 方形。P1—P40 为内容编号，包含封面与封底；正式装订时另核定印刷页码与封面计数。
- 普通故事页正文以约 20—40 个汉字、2—3 行为目标，保留一个主要动作或感受；百科贴纸承担知识解释。章扉、互动页与版权页按功能调整。
- 每页只推进一个发现。不把同一潮池里的多种生物排成展板，也不在礁盘页画"鱼类图鉴"。微小生物通过靠近前景与合理放大呈现，不额外加标本式分框。
- 故事与百科分区排版，贴纸统一为小块米白手账纸样式，标题固定为"海洋小百科"。封面、扉页及收尾页依各自功能安排，不强加百科。
- **绘本文字用孩子会说的话**：两句以内讲清一件事，不出现"因此""从而""进行"这类词；一句话里只有一个转折。
- 图内标题不印 P 页码或页码分隔符。普通标题字高约为正文的 115%，柔和雾蓝或深海绿；正文清晰暖深棕色。章名可适当放大，封面使用独立书名层级。
- 排字优先使用雾光、天空、水面、湿沙或低细节岩面；必要时用轻薄米白底承托。标题、正文、完整贴纸、脸、手与关键动作都需远离裁切边缘。
- 温暖水彩和彩铅卡通风格贯穿全书；潮间带沙金、礁盘青绿、开阔海钴蓝、夜海蓝靛各保留环境色，**不把所有页面统一成金黄夕照**。
- 水中倒影须对应真实物体与视点，不强补被水面、礁石或画框遮住的倒影。水下视角要交代清楚：**是天上看水下，还是水下看水下**，两种画法不能混用。
- 本稿的科普为初稿表述；正式出版前应结合最终物种参考与画面进行事实、字形与文字校对。

## P1｜封面：贝壳图书馆

**图内标题：** 贝壳图书馆

**封面副标题：** 从潮池到远海的蓝色大百科

**画面建议：** 海报式主题封面，儿童视角站在沙丘顶端的木栈道起点，栈道向下弯向一片退潮后的礁滩。前景是湿沙、贝壳与一丛被浪冲上岸的海藻；中景是黑亮的礁石与几个亮着的小水洼；远景是低低的海平线与一层雾。小满站在栈道第一级台阶上，身体微微前倾，一手扶帽檐，一手拎着布包，目光沿栈道望向远处的水线；穿浅蓝白细条纹长袖、米色工装短裤和赭黄色涉水凉鞋，布包露出笔记本与防水画板的米白边角。羽羽在她肩上方轻飞，保留全部戴胜特征与颈间小书挂件。封面只表达"这里可以下去看看"，**不预告任何具体动物**——不画寄居蟹、不画海龟、不画珊瑚，也不放贝壳书签特写。下半部留给人物与海岸，人物全身约画高 38%，脸、手、鞋与主要物体不贴四边。

**封面导语：**

翻开这本书，  
海水会一层一层地，把秘密送上来。

**排版建议：** 书名放在上方浅亮雾光中，副标题紧随其下，字级明显小于书名；导语放在副标题下方一行。封面不放寻找贴纸、百科贴纸或正文对白，不印页码。

## P2｜扉页：书页上有水痕

**图内标题：** 书页上有水痕

**画面建议：** 清晨图书馆，柔和窗光落在儿童低书架上。小满穿米白叶纹长袖、砖红背带裙、白袜和米色室内布鞋，盘腿坐在矮凳上，旧绿皮自然百科摊在膝上。书页边缘有一道浅浅的水痕，正在缓慢晕开，把一小片插图的颜色浸得略深；说明这是刚刚发生的事，不是旧污渍。一枚小小的**贝壳形书签**从书页间探出半截，米白带浅棕纹，与前两作的羽毛书签、叶形书签同属一套造型语言。羽羽停在书脊上，侧头看着那道水痕。窗外是刚晴的院子，窗玻璃上残留着水珠。

**绘本文字：**

星期一，书页上多了一道水痕。  
“是海的味道。”羽羽说。  
小满把贝壳书签，夹进了那一页。

**海洋小百科：** 很多海岸一天会经历两次涨潮和两次落潮，但不同地方的节奏并不完全一样。海面这种有规律的升降叫潮汐。退潮以后，礁石之间凹下去的地方会积起一洼水，叫潮池。

**排版建议：** 标题与正文放在上方安静墙面，画面重点落在下方摊开的书、水痕与那双手。本页不放百科以外的贴纸。

## P3｜第一章：沙与浪之间

**图内标题：** 第一章／沙与浪之间（分两行）

**画面建议：** 承接 P2 书页蓝光，小满穿过书中淡蓝色的光落在一片退潮后的沙滩上。她站在干沙与湿沙的分界线上，一只脚踩在干沙里，另一只脚刚碰到湿沙边缘就停住，鞋底没有浸水；上身略微后倾，一手抓着布包带。前方湿沙上是一道道被海水留下的波纹，再往前是露出水面的礁石与几个亮着的小水洼。羽羽已经落在最近一块礁石上，回头等她。前景是湿沙的水光与几枚自然散落的贝壳，中景是礁石与潮池，远景是低低的水线。**不画任何动物特写**，寄居蟹的发现留到 P4。

**绘本文字：**

潮水退下去了，  
沙滩上留下一个个亮亮的小水洼。  
小满站在水洼边，还没敢把脚伸进去。

**海洋小百科：** 潮间带是海和陆地之间的地带。涨潮时被海水盖住，退潮时露出来，是海边变化最大的地方。

**排版建议：** 章名放在左上浅雾天空，正文紧随其下；百科贴纸置于右下干沙低细节处，避开湿沙反光与小径。

## P4｜小水洼里的搬家队

**图内标题：** 小水洼里的搬家队

**画面建议：** 镜头降到潮池边。小满蹲在池沿，两手撑在膝盖上，身体前倾，视线明确落进水里，眼睛与水面的角度接近 45 度；穿浅蓝条纹长袖、米色短裤与赭黄凉鞋，鞋底踩在干沙上，没有伸进水里。池中一只寄居蟹背着一只螺旋形空螺壳沿池底移动，右侧还有两三只小蟹横向爬过；水面有轻微波纹，能看见小满自己的模糊倒影，倒影里只有脸和帽檐。羽羽停在池边礁石上，身体压低。寄居蟹的壳要画准：壳口朝前、大螯探出、步足抓住池底，**不画成螃蟹背着一个完整的活螺**。

**绘本文字：**

小小的螺壳，自己走起来了。  
“里面住着谁？”  
小满把脸凑得更近了一点。

**海洋小百科：** 寄居蟹住在空螺壳里。它长大以后要换一个更大的壳，换壳之前会先试试合不合适。

**排版建议：** 标题正文放在左上礁石暗部；百科贴纸右下；不遮住壳口、螯与步足的接触点。

## P5｜藤壶是一堵墙

**图内标题：** 藤壶是一堵墙

**画面建议：** 礁石侧面的近距离视角，密密排布的藤壶像一片小小的火山口，边缘泛白，中心有细缝。小满侧身贴在石边，一手扶住岩石保持平衡，另一只手的指尖停在离石面几厘米处、**明确不接触**；掌指结构自然，四指加一拇指，允许被袖子自然遮挡。画面要能看出藤壶分两种状态：多数闭合，靠近水线的一两只张开细小的羽状附肢。羽羽在石顶向下看，羽冠微微竖起。

**绘本文字：**

石头上，长满了小小的火山口。  
“它们也是动物吗？”  
浪花打过来，火山口关上了门。

**海洋小百科：** 藤壶是甲壳类动物，不是石头。它们小时候在水里漂，找到礁石安家以后就不再搬走。张开细小的羽状足，像小网兜一样扫水里的食物。

**排版建议：** 正文放左上石面暗区；百科右下；不遮住张开的羽状足。

## P6｜沙里冒出的气泡

**画面建议：** 退潮后的湿沙面，一小片沙地鼓起，几串细小的气泡从沙里冒出来，沙面上有细小的爬痕通向礁石缝。小满跪在沙上，两膝落在干沙，双手放在膝前、离沙面有一点距离，低头看着冒泡的位置。一只沙蟹的身体从沙里探出一半，颜色与湿沙接近，只有眼睛与螯清楚可辨；**不画成从洞里完整爬出**。羽羽站在旁边礁石上，身体向前倾。

**绘本文字：**

沙地上，冒出一串小气泡。  
“下面藏着谁？”  
沙一动，一只小蟹横着爬了出来。

**海洋小百科：** 沙蟹会把身体埋在湿沙里，躲开干燥和天敌。它们跑得很快，走路是横着的。

**排版建议：** 标题正文右上湿沙背景；百科左下；完整露出气泡与爬痕，不盖住蟹眼与螯。

## P7｜海葵的手

水里有朵会动的花，  
花瓣是软软的小手。  
小满的手，伸到水面上，又停住了。

**海洋小百科：** 海葵的触手上有许多细小的刺细胞，能麻痹靠近的小动物。观察海葵时要保持距离，不要随便触碰。

**排版建议：** 标题左上礁石暗部；百科右下；触手尖端不贴边缘，留出摆动余量。

## P8｜一条会走路的线

**图内标题：** 一条会走路的线

**画面建议：** 潮池底部，一条沙蚕从沙里缓缓探出。身体一节一节，每一节两侧都有一小排短而透明的疣足，贴着沙面轻轻拨动，边缘泛着淡淡的虹彩。小满侧头贴着池沿看，帽檐遮住半边脸，露出眼睛。羽羽低头看水，喙几乎碰到水面。画面以水面为一层薄薄的界，能同时看见水上和水下，**不要做成剖面图**。

**绘本文字：**

池底，一条细细的线，  
慢慢伸长了。  
“它看起来没有脚，是怎么走路的？”

**海洋小百科：** 沙蚕的身体一节一节的，每一节两边都长着一排小小的疣足，像很多小桨。它靠这些"小桨"和身体的伸缩，在沙里和水中移动。退潮后它们常躲在沙下。

**排版建议：** 正文放左上水面倒影区；百科右下；虫体与沙面的接触要清楚。

## P9｜把手放进水里

**绘本文字：**

小满把手慢慢放进水里。  
不凉，也不可怕。  
“原来，海是这个温度。”

**海洋小百科：** 退潮后，潮池里的水会被太阳晒暖。池子越小、水越浅，温度变得越快。

**排版建议：** 标题右上礁石；百科左下；把涟漪圈完整画出，不被文字压住。

## P10｜海水在石头上写字

**图内标题：** 海水在石头上写字

**画面建议：** 礁石立面，几条横向的浅色带叠在一起，最上面一条压着几枚黏附的小贝壳和一小撮海藻，下面几条颜色更沉、更旧。小满侧身站在干沙上，用食指点着最上面那条，指尖离石面几厘米、**不触碰**；视线顺着带走。羽羽沿着同一条带在石面上小步走，形成一条视觉引导线。构图要让读者一眼看出"上面这条是这几天水到过的最高处，下面几条更早、更低"。

**绘本文字：**

石头上，画着一条一条的线。  
“这是谁写的？”  
“是潮水。它有时候写得高，有时候写得低。”

**海洋小百科：** 海水每次涨上来，会在石头上留下一道浅色的痕迹，叫潮线。看这些线，能知道海水到过哪里。

**排版建议：** 正文放在右上水线以上的天空；百科左下；不遮住最上方那条潮线与羽羽所在的位置。

## P11｜一只鸟在石头上等

**图内标题：** 一只鸟在石头上等

**画面建议：** 一只小型涉禽（细腿、细直喙、背灰褐、腹白）站在露出水面的礁石上，身子朝向水，随着退回的浪往前走一步，又随着涌上的浪退半步；喙尖插进湿沙，正在取食。小满坐在干沙上，双膝抱在怀里，安静地看着，**双手抱住膝盖、四指自然包住膝头**。羽羽停在稍高的石头上，第一次露出"它们和我不一样"的神情——羽冠收紧，喙微微张开。画面要能读出潮水正在慢慢回来：湿沙带比前一页更窄。

**绘本文字：**

浪退下去，它往前一步。  
浪涨上来，它退后一步。  
“它比潮水还准时。”

**海洋小百科：** 有些水鸟会跟着潮水的节奏走，在退潮露出的滩面上找食物，涨潮时退回高处休息。

**排版建议：** 标题左上天空；百科右下；鸟的脚与湿沙接触点是本页重点，不能被贴纸盖住。

## P12｜把潮池画成一页

**图内标题：** 把潮池画成一页

**画面建议：** 潮池边一块干燥的礁石平台上，摊开小笔记本，页面上画着一个圆——代表潮池——圆里用简单符号标出寄居蟹的螺旋壳、藤壶的扇形、海葵的一圈触手，圆外写了两个问号。小满坐在石台上，一只脚垂着、一只脚踩着，低头画；草帽摘下来挂在布包带上。羽羽在笔记本边缘，喙指着一处画歪的位置。背景远处，礁石下部已经重新被海水浸没，退路边缘泛着水光——潮水在回来了。这一页是第一章的章末整理页。

**绘本文字：**

一个圆，就是一个小水洼。  
小满画满了，抬起头：  
“水怎么比刚才高了？”

**海洋小百科：** 记录时可以画下形状、位置和动作。潮水开始上涨时，要离开低处礁石，回到岸上。

**排版建议：** 正文左上天空；百科右下；笔记本画面清楚但不塞入微小长文，保留通向岸上的栈道。

## P13｜第二章：石头上的花园

**图内标题：** 第二章／石头上的花园（分两行）

**画面建议：** 近岸礁盘的观察设施入口。小满已换好浅灰蓝薄水母衣和浅灰涉水鞋，面镜挂在颈上；外套和草帽收进岸边的储物木箱，布包仍背在身上（防水画板在包里）。她扶着连续护栏的木栈道往前走，脚下的礁盘已被涨起的海水覆盖，水清得能看见底。羽羽站在栏杆顶上，**没有下水**，身体朝水面倾斜。前景是栏杆与湿木纹，中景是一级一级往下的浮台台阶，远景是层层叠叠的浅水与更远处的深蓝。水面高光要亮，但人物的脸与护栏不能被反光吃掉。

水涨起来了，石头沉到了水下。  
护栏下面，  
露出一个会动的花园。

## P14｜第一次把头埋进水里

**图内标题：** 第一次把头埋进水里

**画面建议：** 浮台最下一级台阶伸进浅水，水深只到小满的膝盖。她跪在台阶上，膝盖与小腿浸在水里，一只手扶住台阶边缘，另一只手扶住面镜，把脸整个贴进水面、屏住一口气；头发浮起来散在水面，后颈露出，**不画成浮在水中央、不使用呼吸管**。水面之下，是她的视角能看到的第一片景象：浅色的礁石、几条游过的小鱼、一缕阳光打在水底形成的光斑。羽羽留在浮台栏杆上，俯身向下看，画面上要明确它是被留在上面的那一方。这是全书情感线的高点之一，人物与水的关系必须清楚、可信、不冒险。

**绘本文字：**

小满戴好面镜，吸一口气。  
脸贴到水面——  
水下，是另一个天空。

**海洋小百科：** 面镜让眼睛在水下也能看清楚。在大人陪同下，可以短时间把面镜浸入水中观察；抬起头以后再换气，不要把脸埋在水里太久。

**排版建议：** 标题放左上浮台木面；百科右下；画面要分层清楚——水上、水面、水下三段，不靠文字压在水下部分。

## P15｜珊瑚是动物还是房子

**图内标题：** 珊瑚是动物还是房子

**画面建议：** 水下视角，一片枝状珊瑚从礁石上长出来，枝端有细小的珊瑚虫触手伸出，随水轻摆；珊瑚枝之间有一条小鱼钻进去又钻出来。小满在画面上方以水面的形式出现，只露脸与水面镜的倒影，**不做成全画幅水下人物**。画面色调以青绿与米白珊瑚为主，光线从水面斜下，形成几道柔和的光柱。要能看出珊瑚的骨骼是硬的、触手是软的，两者质感区分开。

**绘本文字：**

那些像树一样的东西，  
上面开出小小的花。  
“原来不是树，是动物。”

**海洋小百科：** 珊瑚是动物，由许多微小的珊瑚虫组成。珊瑚虫用触手抓水里的小食物，还会分泌石灰质骨骼。骨骼一代代堆积，慢慢长成珊瑚礁。

**排版建议：** 标题在上方水面区域，用薄米白底；百科右下礁石暗部；不遮住触手与鱼的出口。

## P16｜谁在给谁打扫

## P17｜会走路的海星

## P18｜章鱼变了一个颜色

## P21｜潮水把路盖住了

**海洋小百科：** 涨潮以后，礁盘会被水盖住。走礁盘一定要先看潮汐时间，在涨潮前离开。

**排版建议：** 标题放左上雾面天空；百科右下干燥平台；不遮住水面下礁石的模糊轮廓。

## P22｜在水面上画一张花园

小满把水下看到的，一样一样画下来。

## P23｜第三章：辽阔的蓝

## P24｜海面上没有路

**图内标题：** 海面上没有路

四面八方都是水。  
“我们怎么知道，往哪边走？”

**排版建议：** 标题放右上水面高光，用薄米白底；百科左下；不压住海平线与船头方向。

## P25｜跟着海鸟走

## P26｜一座会游泳的岛

**图内标题：** 一座会游泳的岛

**绘本文字：**

海上浮起一块“石头”。  
等了一会儿，  
它动了一下。“是一只会游泳的岛。”

**海洋小百科：** 海龟一生大部分时间在海里，要浮上水面呼吸。它的背甲浮出水面时，远远看去很像一块石头。它们能游很长的距离，也会回到出生的海滩产卵。

**排版建议：** 标题右上；百科左下；不遮住海龟头部与呼吸动作。

## P27｜喷上来的一口水

海面上，突然喷起一道水。  
过一会儿，一个黑色的背冒出来，  
又沉下去。

**海洋小百科：** 鲸用头顶的鼻孔呼吸。呼出的热气遇到凉空气，会变成一团白雾，看起来像喷泉。

**排版建议：** 标题左上天空；百科右下；水柱与背脊的关系完整可见。

## P28｜水面下的一片森林

**图内标题：** 水面下的一片森林

**画面建议：** 透过水面看水下，一片高大的褐绿色海藻从礁石上立起来，底部的小固着器紧紧抓住岩面，叶片细长、随流向一侧摆动，叶柄上带着一个个小小的气囊，让藻体在水中立稳；光从水面斜下，被藻叶切成一束一束。小满趴在船侧护栏上，把面镜按在额头，低头看；**不把画板伸到水里**。羽羽在栏杆上。画面要同时交代两件事：**它不是珊瑚、也不是树**——没有树干，只有一根粗柄；**它也不是漂着的**——底部抓着石头。

水面下，长着高高的“树”。  
它们没有真正的根，  
只靠一个“抓手”抓住石头，把叶子托向阳光。

**海洋小百科：** 海藻没有真正的根、茎、叶。它们用底部的固着器抓住礁石，靠叶片上的气囊让身体在水中立起来，接近阳光。

**排版建议：** 标题上部水面，用薄米白底；百科右下水下暗部；不遮住气囊、固着器与叶片的摆动方向。

## P29｜海上也有垃圾

**图内标题：** 海上也有垃圾

**画面建议：** 船侧不远处的水面上，漂着一个半沉的塑料袋与一小截旧渔网绳，塑料袋在水下摊开成一片淡淡的白，看起来像可以吃的东西。一只海鸟从上方飞过，身体朝下倾斜、又拉起，离开了那片白色。小满的手停在护栏上，表情从笑转成安静，随后转头向船长示意；**不画她探身、伸手或下水去捞**。羽羽在栏杆上不出声，羽冠压低。画面处理要克制：不做动物误食、不做伤口、不做血腥，只画"它差一点认错了"。P30 再由船长使用长柄网安全捞起。

**绘本文字：**

海面上，漂着一个塑料袋。  
一只鸟飞过去，又绕开了。  
“船长，它是不是把塑料袋当成吃的了？我们能把它带回岸上吗？”

**海洋小百科：** 海里的塑料垃圾会被动物误当成食物。在确保安全并由大人操作时，可以用工具把漂浮垃圾捞起；不要探身或下水去捡。

**排版建议：** 标题右上；百科右下；塑料袋要画得轻、薄、半透，不画成恐怖道具。

## P30｜回岸了

## P32｜第四章：潮水回来的时候

**图内标题：** 第四章／潮水回来的时候（分两行）

**画面建议：** 夜，月亮在画面左上方偏低的位置，海面呈深蓝靛色。小满已加薄珊瑚色外套、长裤与赭黄涉水鞋，站在海滩上方一段有连续护栏的木栈道上；头灯戴在额前，光线压低，只照脚下台阶、近处湿沙和紧邻栈道的一小片水面，**不长时间直射动物，也不扫向远处海面**。羽羽停在栏杆顶上，身体缩成小小一团。前景是栈道木纹与一段湿沙，中景是黑色水面上一道道涌上来的白色浪线，远景是模糊的礁石轮廓。夜色里人物仍要清楚可辨，靠月光与头灯的低照度分层。

## P33｜夜里，它们出来了

**图内标题：** 夜里，它们出来了

## P34｜沙上留下的一条痕

**图内标题：** 沙上留下的一条痕

**画面建议：** 月光在湿沙上铺出一条偏银色的亮带，从栈道下一直延伸到水边。一道浅浅的拖痕横过亮带，宽度很窄，两侧有小点状的足迹——是某种小动物刚刚爬过的证据，**不画那只动物本身**。小满蹲在栈道最后一阶上，脚尖没有踩上湿沙，头灯照在痕迹的一端，光压得很低。画面要有"刚发生过"的时间感：痕迹边缘还湿，旁边没有其他脚印。

## P35｜潮水回来了

**图内标题：** 潮水回来了

**画面建议：** 一层一层白色的浪线涌上沙滩，先把 P33、P34 蹲过的那一级台阶打湿，再把 P34 的痕迹、白天留下的所有脚印一点点推平、抹掉。小满已经退到栈道更高的一级，站着看，双手扶着护栏。羽羽在栏杆上。画面的重音是**水线**——一条清晰的、正在移动的白色边界。其余全部压暗，只留月光、浪线与小满的脚。不画危险，只画"它把这里重新写了一遍"。

**绘本文字：**

“它把沙滩，重新写了一遍。”

**排版建议：** 标题左上夜空；百科右下栈道；不遮住水线推进的方向与被打湿的最低一级台阶。

## 使用说明

这张表只解决一件事：**哪些部位画错了，懂行的家长和孩子会当场发现。**

低幼绘本不必每一只都精确到种，但**必须做到两件事**——第一，凡是出现在百科贴纸上的物种，外形要落进它所属的类群；第二，同一个物种出现在不同页时，形态、配色与比例要一致。因此本表先分级，再逐种给卡片。

表内不指定具体种名的地方，是刻意留白：写"参考类群"即允许在类群范围内选择，但**不允许跨出这个范围**。

## A 级物种卡

### 1. 寄居蟹（P4、P9、P40）

**参考类群：** 寄居蟹科（Paguridae）潮间带类群，如方腕寄居蟹一类。

**必对特征：**
- 身体**左右不对称**，柔软的腹部呈螺旋状，整个藏在**空螺壳**里。
- **右螯明显大于左螯**（多数种类），大螯在受惊时用来堵住壳口。
- 步足末端尖，抓在池底或壳缘；触角与一对眼从壳口伸出。
- 外出时壳**背在背上**，壳口朝前，随身体移动。
- 受惊时整个身体缩进壳里，只剩壳口对着外面（P9）。

**易错点：**
- 画成一只螃蟹背着**活的螺**。壳必须是空的、死的、没有软体动物探出。
- 把身体画成对称的，或者把柔软的腹部露在壳外。
- 壳口朝后，或壳与身体方向错位。
- 体型画大。真实壳长多在 1—3 cm，画面上约为小满手掌的三分之一。

**跨页一致：** P4 的壳形与 P9、P40 必须是同一只（螺旋方向、斑纹一致）。

### 2. 藤壶（P5、P10）

**参考类群：** 笠藤壶类群（潮间带礁石上常见）。

**必对特征：**
- 外形是**锥形或火山口形**的小壳，由几片壳板围成，顶端开口处有细缝。
- 紧紧**固着**在礁石表面，成群密布，形成一条带。
- 摄食时从开口伸出**羽状的蔓足**，像一把小网兜在水里扫。
- 退潮暴露时**闭合**，只留一条细缝，看起来像死掉的石头。

**易错点：**
- 画成小石头、火山岩或蘑菇。
- 画成双壳贝类（贻贝那种两瓣壳）。
- 把蔓足画成鱿鱼式触手（应该是有分节感、带刚毛的羽状）。
- 画成会移动的动物。藤壶定居后终身不动。

### 3. 沙蟹（P6）

**参考类群：** 沙蟹科（Ocypodidae）潮间带类群。

**必对特征：**
- 甲壳偏**方形**，不是圆壳。
- 眼睛长在**突出的眼柄**上（沙蟹类特征鲜明）。
- 两只螯大小常不等。
- 埋在湿沙里时只露出眼与螯；受惊后**横向快跑**，速度极快。

**易错点：**
- 画成圆形甲壳的蟹。
- 画成"纵向奔跑"或"从洞里整只爬出"。
- 把埋沙状态画成半透明的剖面。

### 4. 海葵（P7）

**参考类群：** 海葵目（Actiniaria）潮间带类群，如纵条矶海葵一类。

**必对特征：**
- 圆柱形的身体，**基部固着在石缝或石面上**，不能悬浮。
- 顶端一圈触手，**数量固定**（同一页内必须一致），伸出时张开，受扰时整圈缩回成一团。
- 触手柔软、随水摆动，与珊瑚的硬骨骼形成对比。

**易错点：**
- 画成花或植物（这是本页最常见错误）。
- 触手数量每页变一次。
- 把基部画成"扎根在沙里"。

### 5. 沙蚕（P8、P33）

**参考类群：** 沙蚕科（Nereididae）类群。

**必对特征：**
- 身体**分节明显**，一节接一节，前端稍粗。
- **每一节两侧各有一对疣足**，肉质、短小、带刚毛，是它的运动器官。
- 身体半透明，边缘有虹彩；在沙面或水中靠身体波浪式伸缩 + 疣足拨动前进。

**易错点：**
- 画成蚯蚓（光滑、无疣足）。
- 画成蜈蚣（疣足画成硬质分节的腿）。
- 画成"一条光滑的线"——这样 P8 的标题"一条会走路的线"就失去对照，孩子的"看起来没有脚"也就没有可被推翻的对象。

**这条最关键：** 绘本文字说的是"**看起来**没有脚"。所以画面上**必须**让读者能看到那一排小疣足，否则这句童言就没有落点，百科的纠正也无从发生。

### 6. 枝状珊瑚（P15）

**参考类群：** 亚热带礁盘边缘的枝状造礁珊瑚。

**必对特征：**
- **分枝状硬骨骼**，枝端有细小的珊瑚虫，触手伸出时像一朵朵小花。
- 珊瑚虫体极小，是**群体**，不是一只大动物。
- 附着在礁石上生长，不能悬空。
- 受触时整枝的触手一起缩回。

**易错点：**
- 画成一棵树或一丛灌木（有主干、有树皮）。
- 把整片珊瑚画成一只动物。
- 触手画成花瓣状、带花蕊。
- 配色用荧光色。亚热带礁盘珊瑚以米白、褐、青灰为主，不使用热带珊瑚的艳粉艳紫。

### 7. 清洁虾（P16）

**参考类群：** 鞭腕虾一类（岩礁上的清洁虾）。

**必对特征：**
- 身体**半透明**，带细白或红褐纵纹。
- 一对**极长的细触须**向前伸，摆动不停。
- 额角呈锯齿状。
- 站立在礁石突出点上，摆出"招揽"姿势；有鱼靠近时爬上鱼体清理。

**易错点：**
- 画成小龙虾（有粗大螯、体色红）。
- 画成"咬着鱼"或"刺进鱼体"的姿态。这一页的关键是**鱼主动停下来张开鳍**、小虾轻轻擦，两者的相对位置必须平和。

### 8. 海星（P17）

**参考类群：** 海星纲（Asteroidea）五腕类群。

**必对特征：**
- **五腕**（本页必须严格五条），中央一个盘。
- 腕的**下侧**有密集的细小管足，靠吸盘与水压移动。
- 身体扁平贴石，移动极慢，磨过去而不是跨过去。

**易错点：**
- 腕数画成六条或不等长。
- 把"脚"画在腕的外侧或画成一节节虾腿。
- 画成快速爬行、有速度线。

### 9. 章鱼（P18）

**参考类群：** 章鱼科（Octopodidae）浅海类群。

**必对特征：**
- **八条腕**，每条腕上有两列吸盘，吸盘在腕的**内侧/腹面**。
- 眼大，位于头顶两侧。
- 皮肤能迅速变色，纹理可与礁石、藻类接近。
- 受惊时喷墨。

**易错点：**
- 画成十条腕（最容易犯的错，多数人凭印象画多）。
- 吸盘画在腕的背面或画成正圆点状排列。
- 为了"找到它"而把轮廓画得过于清晰——这一页的趣味恰恰是**轮廓与礁石融合，只留一只眼睛可辨**。

### 10. 海龟（P26）

**参考类群：** 绿海龟一类（亚热带近海常见）。

**必对特征：**
- 背甲**流线扁平**，不是高高拱起的圆顶。
- **前肢长而呈桨状**，明显大于后肢；后肢短、像舵。
- 头**不能缩回壳内**。
- 浮出水面时只露背甲一小块与抬起的头，四肢大多在水下。

**易错点：**
- 画成陆龟（高拱背甲、柱状腿、能缩头）。
- 前肢与后肢画成同样大小、同样形状。
- 在背甲上画一只站着的鸟（本稿已明确禁止）。
- 体型画大。真实成体背甲 60—100 cm，但在中景里应该"远看像一块小石头"。

### 11. 鲸（P27，限定画法）

**参考类群：** 不指定种。本页只允许画**背脊 + 水柱**。

**必对特征：**
- 喷气孔位于**头顶**，不是头侧。
- 水柱是呼出热气遇冷凝结的白雾，加上少量带起的水，**不是喷出的水枪**。
- 露出水面的部分只有一小截背脊，尾鳍**水平**（不是鱼那样的竖直尾）。

**易错点：**
- 鼻孔画在头侧（那是鱼，不是鲸）。
- 画成整条跃出水面的鲸，或画成大尾巴。
- 水柱画成一条实心白色水线，或从嘴里喷出。

**这一页的克制要求：** 全书只此一处鲸，且只给"一个背 + 一道水柱"。不要加第二条、不要加尾鳍特写。

### 12. 褐藻（马尾藻类，P28）

**参考类群：** 马尾藻类（Sargassum）近岸固着类群。

**必对特征：**
- 底部是**固着器**，盘状或短根状，**紧紧抓住礁石**。
- 藻体没有真正的根、茎、叶，只有反复分枝的**藻体与叶片状的藻片**。
- 叶柄上带**球形气囊**，让藻体在水中立起来、接近阳光。
- 整丛随水流向一侧摆，但底部不动。

**易错点（本页已被改过一次，务必留意）：**
- 画成漂浮在海面、没有固着器的一团（错）。
- 画成海草——有根扎进沙里、有花（错，海草是另一个类群）。
- 画成树——有树干、树皮（错）。
- 把气囊画成气泡或果实。
- 在画面里加入"沉在水底"的根须状结构——**固着器只抓岩石，不进沙**。

## B 级物种卡

### 13. 涉禽（P11）
**参考类群：** 鹬科（Scolopacidae）类群。细腿、**细而直的喙**、前趾三趾无蹼、背灰褐腹白。可画行走时点头啄食、单腿站立。
**不可画成：** 鹭或鹤（喙过长、腿过粗、颈过长）、麻雀体型、蹼足。
**允许不指定种，但外形必须落在鹬科范围内。**

### 14. 礁缝小鱼（P19）
**参考类群：** 鳚科或虾虎鱼类群。体小、无大鳞、不起眼的褐灰色。
**不可画成：** 霓虹色观赏鱼、热带珊瑚礁的彩色鱼。

### 15. 银蓝色小鱼群（P20）
**参考类群：** 鲱科或鳀科类群。银色体侧有反光带、群体同向、转身同步。
**不可画成：** 每一条都不同颜色、或者画成热带鱼群。

### 16. 海鸟（P25、P26、P29）
**参考类群：** 鸥科或海鸟类的白色系类群。白身、深色翼尖、贴浪低飞。
**不可画成：** 企鹅、热带海鸟（如鹦鹉嘴状）、戴胜。
**特别提醒：** 羽羽在同一页出现时，必须让读者一眼分得出它与野生海鸟——羽羽有羽冠、细长弯喙、书签尾和颈间小书，**野生海鸟一概不带这些**。

### 17. 夜行蟹与端足类（P33）
**参考类群：** 潮间带夜行性蟹类；端足类（侧扁的小型甲壳动物）。
**处理：** 端足类可以高度简化成藻叶间的小弯点，不承担识别。夜行蟹沿用 P6 的形态语言，只是换到月光色。

## C 级环境元素

- **散落贝壳**（P1、P3、P40）：不画成活的软体动物，不指定种；螺旋与扇形都不超过两三种，避免像"贝壳展板"。
- **礁面附着物**（P10）：可沿用 P5 藤壶的形态语言，也可点几枚小贻贝。
- **潮线**（P10、P39）：是"浅色带"，不是画一条黑线；边缘要自然、起伏不齐。
- **沙面痕迹**（P34）：拖痕 + 小点足迹，宽度约为小满一根手指的三分之一。

## S 级：羽羽

**固定项（不得改动）：** 金棕色身体、黑尖肉桂色扇形羽冠、细长微下弯黑喙、黑白横斑翅膀、书签状尾羽、颈间砖红金边羽叶纹小书挂件。

**本作新增的行为约束：** 全程不下水；只停在栏杆、礁石、缆绳等高于水面的支承物上。

**易错点：** 被画成海鸥、鹦鹉、玄凤鹦鹉；被浪打湿后整只湿透（只允许溅湿几根，P22）；羽冠在飞行与发现时竖起，在安静时收起。

## 禁入清单（红牌）

以下物种只要出现一处，就说明有人越出了设定海域，需要返工：

- **极地类**：企鹅、海豹、北极熊、海冰场景。
- **深海类**：热泉管虫、盲虾、深海发光生物。
- **热带珊瑚三角区特有**：海葵鱼、鹿角珊瑚的艳色变种、大型砗磲。
- **亚洲内陆/淡水**：亚洲犀鸟、大象、老虎、亚洲淡水鱼。
- **未在设定内的大型动物**：鲨鱼、海豚、海狮（本作不涉及，勿"顺手加一只"）。

## 比例基准

以画面里的小满（约 110 cm 高）为尺，各物种在页面上的相对大小：

| 物种 | 真实尺寸 | 在画面上的处理 |
| --- | --- | --- |
| 寄居蟹 | 壳长 1—3 cm | 约为小满手掌的 1/3；特写页可放大到手掌大，但不超过 |
| 藤壶单只 | 0.5—2 cm | 密集排列成带，单个不超过指尖 |
| 沙蟹 | 甲宽 1—3 cm | 不超过小满的手掌 |
| 海葵 | 直径 3—8 cm | 约为小满的拳头到张开的手 |
| 沙蚕 | 体长 5—15 cm | 可拉长，但身体粗细不超过小指 |
| 海星 | 腕展 5—15 cm | 约为张开的手掌 |
| 章鱼 | 腕展 20—40 cm | 只见局部，不画成整只摊开的巨型章鱼 |
| 清洁虾 | 体长 3—6 cm | 约为小满的一根手指 |
| 海龟 | 背甲 60—100 cm | 中景里"远看像一块小石头"，不作近距离对视 |
| 鲸 | — | 只露背脊与水柱，永远在远景 |
| 褐藻丛 | 高 1—3 m | 高于小满，但仍能看出底部抓着石头 |

## 色彩锚点

同一个物种跨页不得变色，各页光源变化只能影响明度，不能改变固有色。

| 对象 | 主色方向 |
| --- | --- |
| 寄居蟹的壳 | 米白、浅褐、带细纹 |
| 藤壶 | 灰白到浅灰，边缘泛白 |
| 沙蟹 | 与湿沙接近的灰褐，只有眼与螯清楚 |
| 海葵 | 米黄、浅粉褐，触手半透明 |
| 沙蚕 | 半透明粉褐，边缘虹彩 |
| 枝状珊瑚 | 米白、浅褐、青灰（不用荧光色） |
| 清洁虾 | 半透明带细白纵纹 |
| 海星 | 橙褐或浅紫褐，贴石 |
| 章鱼 | 随所在礁石变色（本页以灰褐为主） |
| 海龟 | 背甲深褐带浅纹，腹甲浅 |
| 褐藻 | 褐绿、橄榄绿 |
| 涉禽 | 背灰褐、腹白、腿黄褐 |

## 审校流程

1. **构图前**：按"逐页物种索引"核对本页物种与级别，确认没有跨级。
2. **线稿完成**：A 级物种按"必对特征"逐条打勾，B 级只核类群。
3. **上色前**：对照"色彩锚点"，确认同一物种与前页一致。
4. **成稿后**：对照"禁入清单"扫一遍全篇。
5. **终审**：A 级物种交海洋生物方向审校；审校只核外形与行为，不改故事。

**一句话原则：** 孩子会盯着画得最仔细的那只动物看很久。**把功夫花在 A 级，把克制留给 B 级。**
