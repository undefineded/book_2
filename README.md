## 文件范围

雨林共40张无字原图、40张标题正文、37张纸签，合计117个PNG。无字图全部1254×1254，逐字节保留所选原文件；P13采用已修正两侧护栏的版本。既有标题正文保留2400px宽，纸签保留2000px宽，RGBA透明，300 PPI。P15两张文字层已按P16手写风格修订，保留图像工具实际输出：标题正文1816×866、百科1254×1254，RGBA，无PPI元数据，未额外缩放。所有正式素材均按实际文件尺寸交付。

P1、P2、P38无右侧百科。P37为观察记录，P39为亲子延伸，P40为回想提示。标题正文和纸签可以独立摆放。

鸟类正在按新剧本重绘全书，正式素材与实际完成状态见鸟类素材索引。每页独立保存无字原图、手写标题正文与该页需要的小贴士；重新构图并缩小主体，为四边与装订留出环境缓冲。鸟类尚未提供阅读PDF。非洲草原目前仅有剧本和约束，保持第一稿状态，不把未制作的图页记为完成。

鸟类现按“栖息地—鸟鸣—身体绝技—日常生活与返程”重排，章扉为P3/P13/P21/P30；旧参考资源的页码须按对照表匹配。

本仓库不收录扩图、超分、Qwen重制、旧整页、重复合画、预览、制作日志、缓存或工具源码。

## 阅读PDF

雨林阅读版由当前1254px无字图与独立手写PNG排版合成，包含P13护栏修正及P15文字风格修订，P1—P40顺序连续，带逐页书签。画幅为600×600pt方形，整页采用高质量JPEG阅读压缩；独立正式PNG保持原文件。本PDF用于屏幕阅读和审阅，不包含出血、印刷色彩配置或虚构出版信息。
