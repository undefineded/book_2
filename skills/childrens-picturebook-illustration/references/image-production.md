# 图片生产与验收规范

本文件属于`childrens-picturebook-illustration` Skill，与[通用制图约束](../../../制图规范/通用制图约束规范.md)共同使用。用户最新指示和项目正式规范优先，不能根据旧提示词扩大制作范围。

## 1. 生成前固定输入

- 对照正式剧本、当前素材及本页确认修订，明确页面角色、逐字文案、场景、服装、鞋、动作、动物数量及道具。
- 查看实际参考图。局部修订锁定其余构图与人物身份，不重新设计整页；未附参考图时不假定能够访问旧聊天附件。
- 雨林手写样式以P16的[标题正文](../../../热带雨林绘本/正式素材/P16｜远处是谁在打鼓/标题与正文-透明底.png)和[百科纸签](../../../热带雨林绘本/正式素材/P16｜远处是谁在打鼓/雨林小百科-透明底.png)为准；其他页使用各自文案。
- 核对输入尺寸、输出目录和可用空间。像素、PPI、打印尺寸分别记录；设置300 PPI不等于增加细节，服务输出尺寸不等于已知的模型内部原生尺寸。

## 2. 无字场景与源图保存

- 无字场景与文字素材分别制作。去字时恢复连续、真实的环境，不保留涂白、模糊块、纸签轮廓或人为文字空区；真实天空、墙面、书页及P37实体观察纸按用途保留。
- 保留人物身份、年龄、服装、站坐姿、手部接触、动物种类数量和羽羽标志，去字不构成重设计授权。
- 现有雨林正式无字图为1254×1254 RGB PNG，以`无字图-1254px.png`保存在各页正式素材目录。逐字节复制并核对SHA-256，不为了设置PPI改写场景文件。
- 新图保留生成文件实际像素尺寸；若不符合交付要求先核实原因，不插值放大或从成品缩小后冒充原始源图。来源文件须在持久目录或已提交仓库保存，不能只依赖`/tmp`。
- **Agent不再执行CPU/GPU超分，也不为提高场景分辨率插值放大。** 本仓库不附超分工具、模型或旧超分产物；用户本地操作另行决定，不自动提交本地衍生成果。

## 3. 透明文字与局部修字

- 标题正文和纸签独立交付。若生成时合画，两块不接触，之间保留全高透明裁切带；裁切后只交付正式独立素材，不附重复合画。
- 保留确认的手写笔锋、字重、字号、配色和行距，不用电脑字体替代手写字。标题正文带米白暖奶油渐变阅读底，四周自然渐隐透明；纸签保留纸张、标题条、叶饰及边框，纸外透明。
- 棋盘格不能烘焙进成品。不得切字、切纸边或丢叶饰，须保留透明边距并检查RGBA和Alpha通道。
- 按正式剧本逐字检查文案、标点、漏字、重字和断行，不打印页码、制作指令或未确认版权信息。OCR和源字符串不能代替最终PNG笔画检查。
- 错字在用户指定图上局部修订，保留其余笔锋、字号、布局与背景；不为修一字重排整行。可记录修补区域并核对区域外像素。
- P16正文`呜——呜——`的“乌”部无眼点，小百科`共鸣`保留“鸣”；P4保留已确认“咦”的字形。
- 仅修订场景时，未被要求修改的文字PNG逐字节复用，不随场景尺寸改变独立素材分辨率。

## 4. 正式文件与页面角色

目录及全部页链接见[仓库README](../../../README.md)，雨林路径为`热带雨林绘本/正式素材/P页码｜标题/`。

| 文件 | 当前要求 |
|---|---|
| `无字图-1254px.png` | 当前确认的无字场景，1254×1254 RGB |
| `标题与正文-透明底.png` | 手写标题正文与渐变阅读底，保留2400px宽、RGBA、300 PPI |
| `雨林小百科-透明底.png` | 独立手绘纸签，保留2000px宽、RGBA、300 PPI |

上表为既有文字素材规格。P15手写风格修订版保留工具实际输出：标题正文1816×866、百科1254×1254，均为RGBA，无PPI元数据，不额外插值放大。标题、正文及百科的笔触、粗细变化和配色对齐P16，不回退到此前偏细僵直的风格。

P1、P2、P38没有百科；P37为`观察记录-透明底.png`，P39为`亲子延伸-透明底.png`，P40为`回想提示-透明底.png`。不生成空白或虚构百科。P37保留填写线、来源勾选框、声音线索和画图区；P38不输出未确认署名、ISBN或版权占位符。

## 5. 阅读PDF与边距

- 用当前无字场景和独立手写文字排版，依页码数值顺序合成；不能沿用包含旧画面的PDF。
- 文字避开脸、双手、动物动作、道具与重要倒影，文字主体距裁切边约12%作为构图参考，不把它当作已确认的印厂工艺。
- 当前雨林阅读版为40页600×600pt方形PDF，包含40个逐页书签，整页采用高质量JPEG阅读压缩；独立正式PNG不改写。
- 核对实际渲染、文字完整性、页序和书签。阅读版不添加未经确认的出血、色彩配置、出版信息或印刷标记，不把屏幕阅读规格称为印刷生产规格。

## 6. 验收与后续交接

- 先看完整场景，再分别放大双手、字形和关键细节。检查四指加拇指的结构、自然遮挡、肩肘腕连接、接触受力、重心及坐姿支撑，不强求任何角度都露出五个指尖。
- 核对脸型年龄、服装鞋帽、动物种类数量、羽羽的戴胜特征和挂件、楼梯护栏、水面倒影、道具及页面文案；缩略图不足以验收手部或字形。
- 检查PNG可读性、实际尺寸、RGB/RGBA、透明边缘、来源哈希和文档链接，修改路径后同步README、规范和本Skill。只记录真正执行的检查。
- 实际文件决定完成状态：雨林已有40页正式分层素材及阅读PDF；鸟类按新剧本逐页制作，状态见[鸟类素材索引](../../../鸟类绘本/正式素材/README.md)；草原目前只有剧本、规范。不能用占位图或带字整页冒充无字分层素材。
- 生成接口返回`usage_limit_reached`时停止新生成请求，保存已完成文件和待办，恢复时间按接口写清绝对日期、时区及不确定性；不推断固定额度，不转为超分。
- 替换前核实当前文件可从Git提交恢复。只有用户明确要求时重置历史；没有可核实旧提交时不能承诺恢复已删文件。
- 已有上传授权时，验收后提交、推送并核实远端；没有授权时仅保存本地。区分已生成、已暂存、已提交与已上传状态。
