# 录音机：用户确认款

[手部比例与造型参考](录音机统一造型.png)直接从用户选中的P24《风里的飞行高手》原图无损裁出，未缩放，不是重新设计的设备。以图中录音机与手的关系为准，不照搬参考中的服装、表情或背景。

- 深灰色小型竖式机身，顶部只有一个圆形灰色绒毛防风罩。
- 上方浅色小屏，屏下小红键，下半部圆形控制区；机身、毛罩及按键布局都沿用参考，不随页面换款。
- 手持时保持参考的机身与手掌比例，单手能自然握持；按人物远近、朝向和透视变化，不能用所有页面同一像素大小代替比例核对。
- 桌面、包侧收纳也必须是同一台实物，不能变大音箱、台式控制台、双毛球、双麦头或没有毛罩的另一款。
- 每个场景只出现一台；正在手持或桌面使用时，布包侧面不再外挂第二台。剧本未要求展示时可收在包内。
- P24是用户选中的标准原图，保留其录音机和手部不改；其余出现设备的页面向它统一。
