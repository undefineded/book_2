# 小满与羽羽 · 独立角色立绘

本目录提供两张无场景、无文字的透明底角色素材，用于绘本排版、角色对照和后续制图参考。

- [小满透明底立绘](小满-透明底.png)：1024×1536，RGBA。沿用封面设定的短发黄花发夹、米白叶纹上衣、砖红背带裙、布包、笔记本和彩铅；包侧录音机采用已确认的灰色毛罩、小屏、红键和圆形控制区造型。
- [羽羽透明底立绘](羽羽-透明底.png)：1536×1024，RGBA。保留金棕身体、黑尖扇形羽冠、细长微弯喙、黑白横斑翅、书签尾和砖红金边小书挂件。

两张立绘分别只包含一个角色，四角透明，不含场景、地面、文字、边框和其他鸟类。它们用于统一角色特征，不替代逐页剧本规定的服装、动作、视线和环境适配。
